Weekly check (5 items)
1. Regular B. 2.5x < 10
   The open circle at 4 shows that 4 is not included, and the shading to the left shows x < 4.
   2.5x < 10 has this solution: dividing both sides by 2.5 gives x < 4.
   2.5x ≤ 10 would need a closed circle; 2.5x > 10 shades the other direction; x + 2.5 < 10 has the boundary 7.5.

2. Regular x ≤ 4.5
   Divide both sides by −7.
   Dividing by a negative number reverses the inequality symbol.
   x ≤ −31.5 ÷ (−7) = 4.5

3. Regular z ≥ −9.7
   Subtract 3.5 from both sides.
   z ≥ −6.2 − 3.5 = −9.7.

4. Regular x < −4
   "The product of a number x and −0.5" is −0.5x, and "greater than 2" gives −0.5x > 2.
   Divide both sides by −0.5. Because it is negative, the inequality symbol reverses: x < −4.

5. Rigor 1.25b ≤ 42; b ≤ 33.6; the greatest number of boxes is 33.
   The weight of b boxes is 1.25b, and it can be at most 42: 1.25b ≤ 42.
   Divide both sides by 1.25: b ≤ 33.6.
   The number of boxes is a whole number, so the greatest number is 33. (34 boxes would weigh 42.5 pounds, which is too much.)

   A joining fee, a starting charge, or a starting height means the relationship is not proportional.

1. Regular A line plot, because the data are numbers with only a few different values, so every value can be shown.

   The data are numbers with only a few different values (0 to 6), so a line plot keeps every value and shows the shape; a stem-and-leaf plot would put every value
   on one stem, and a histogram would hide the individual values.
   Count how many times each value occurs, then stack that many Xs above the value on a number line.
   0: 3; 2: 4; 4: 1; 5: 1; 6: 2.

2. Regular B. a histogram
   There are 150 values, almost all different, so a line plot or a stem-and-leaf plot would need a mark or a leaf for nearly every value, and the table gives only
   counts for intervals.
   The data are numerical, so a circle graph (parts of a whole) does not fit. A histogram uses the equal intervals in the table as its bars and shows the shape of the
   distribution.

3. Regular C. a circle graph
   The question compares one category with the whole. In a circle graph each section is the same fraction of the circle as its category is of the total, so a section
   can be compared with half of the circle at a glance (Fiction is 35%).
   A bar chart shows the amounts but not how each compares with the total; a histogram and a line plot are for numerical data.

4. Regular D. a stem-and-leaf plot
   The values are spread over several tens, from 23 to 67, with few repeats. A stem-and-leaf plot keeps every value (the leaves) and shows the shape (the stems).
   A line plot would need a place for almost every number from 23 to 67, with few marks stacked.

5. Rigor A. a line plot of the data; B. a stem-and-leaf plot of the data; C. a box plot of the data
   A line plot keeps every value, so the range can be found from it. A stem-and-leaf plot keeps every value, so the range can be found from it. A box plot marks the
   minimum, the median and the maximum, so it gives the range exactly.
   A histogram and a circle graph of intervals only show how many values are in each interval, so the exact least and greatest values cannot be read from them.
