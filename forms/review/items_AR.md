### Q1  type: Multiple choice  (generator label: Unit conversions across measurement systems)
STEM: 1 kilogram ≈ 2.2 pounds. / A suitcase weighs 40 pounds. What is its mass in kilograms, to the nearest tenth?
  A. 1.8 kilograms
  B. 37.8 kilograms
  C. 18.2 kilograms
  D. 88.0 kilograms
KEY: C
SOLUTION: Each kilogram is about 2.2 pounds, so there are fewer kilograms than pounds: divide by 2.2. / 40 ÷ 2.2 ≈ 18.182, which rounds to 18.2 kilograms.

### Q2  type: Short answer  (generator label: Unit conversions across measurement systems)

KEY: typed: 58.75
SOLUTION: Each dollar becomes 0.9 Swiss francs: 100 × 0.9 = 90.00 Swiss francs. / Subtract the meal: 90.00 − 31.25 = 58.75 Swiss francs.

### Q1  type: Multiple choice  (generator label: Solve problems involving proportions)
STEM: In a trail mix, the ratio of peanuts to raisins is 28:16. A hiker uses 20 ounces of raisins. / Which choice shows a proportion that can be used to find p, the number of ounces of peanuts that keeps the same ratio, and the correct value of p?
  A. 28/16 = p/20; p = 35
  B. 28/20 = p/16; p = 22.4
  C. 28/20 = p/16; p = 35
  D. 28/16 = p/20; p = 32
KEY: A
SOLUTION: Peanuts to raisins is 28 to 16, so keep peanuts on top and raisins on the bottom on both sides: 28/16 = p/20. / Cross-multiply: 16p = 28 × 20 = 560, so p = 560 ÷ 16 = 35 ounces. / 28/20 = p/16 pairs the mix's peanuts with the hiker's raisins, so it does not keep the ratio (it gives p = 22.4). p = 32 adds 4 to 28 because 20 is 4 more than 16; a ratio is kept by multiplying, not adding.

### Q4  type: Multiple choice  (generator label: Real-world proportional problems)
STEM: A car uses gas at a constant rate. It travels 154 miles on 5.5 gallons of gas. / How many gallons of gas are needed to travel 210 miles?
  A. 38.2 gallons
  B. 6.9 gallons
  C. 4.0 gallons
  D. 7.5 gallons
KEY: D
SOLUTION: Unit rate: 154 ÷ 5.5 = 28 miles per gallon. Then 210 ÷ 28 = 7.5 gallons. / 4.0 gallons (5.5 × 154 ÷ 210) turns the ratio upside down; 38.2 gallons (210 ÷ 5.5) treats 5.5 as miles per gallon; 6.9 gallons (5.5 + 210 ÷ 154) adds the scale factor instead of multiplying by it.

### Q1  type: Multiple choice  (generator label: Simplify linear expressions)
STEM: Which expression is equivalent to the expression shown, written with the fewest possible terms? / (3 + (5/6)p) + ((5/6)p − 1)
  A. (5/6)p + 2
  B. (5/3)p + 4
  C. (5/3)p + 2
  D. (11/3)p
KEY: C
SOLUTION: Group like terms: (5/6)p + (5/6)p = (10/6)p = (5/3)p, and 3 + (−1) = 2. The expression is (5/3)p + 2. / (5/6)p + 2 counts only one of the p-terms, (5/3)p + 4 treats −1 as +1, and (11/3)p adds the constant into the p-term, but unlike terms cannot be combined.

### Q2  type: Multiple choice  (generator label: Simplify linear expressions)

KEY: A
SOLUTION: Add the x-terms: 0.4x + 1.6x = 2x. Add the constants: 2 − 2.5 = −0.5. / An x-term and a constant cannot be combined into one term.
